# Danh sách dịch thuật (Language Packs)

Dưới đây là nội dung đã dịch cho các ngôn ngữ phổ biến. Bạn hãy mở file `strings.xml` tương ứng trong thư mục `values-<lang_code>` và thay thế nội dung bằng khối code bên dưới.

## 1. Tiếng Pháp (values-fr)
```xml
<resources>
    <string name="app_name" translatable="false">Pion base</string>
    <string name="hd_wallpaper" translatable="false">HD Wallpaper</string>
    <string name="featured">En vedette</string>
    <string name="top_wallpaper">Meilleurs fonds d\'écran</string>
    <string name="see_more">Voir plus</string>
    <string name="home_tab">Accueil</string>
    <string name="categories_tab">Catégories</string>
    <string name="setting">Paramètres</string>
    <string name="update_profile">Mettre à jour le profil</string>
    <string name="language">Langue</string>
    <string name="dark_theme">Thème sombre</string>
    <string name="auto_change_wallpaper">Changement auto. de fond d\'écran</string>
    <string name="enable_notifications">Activer les notifications</string>
    <string name="rate_this_app">Noter l\'application</string>
    <string name="share_with_friend">Partager avec un ami</string>
    <string name="select_custom_wallpaper">Choisir un fond d\'écran personnalisé</string>
    <string name="please_select_language">Veuillez sélectionner une langue</string>
    <string name="close">Fermer</string>
    <string name="cancel">Annuler</string>
    <string name="this_is_demo">Ceci est une boîte de dialogue de démonstration</string>
    <string name="pion_tech">Pion Tech</string>
    <string name="website_url" translatable="false">https://piontech.co</string>
    <string name="facebook">Facebook :</string>
    <string name="telegram">Télégramme :</string>
    <string name="piontechglobal" translatable="false">@piontechglobal</string>
    <string name="my_favorites">Mes favoris</string>
    <string name="no_favorites_yet">Aucun favori pour le moment</string>
    <string name="ok">OK</string>
    <string name="next">Suivant</string>
    <string name="no_results_found">Aucun résultat trouvé</string>
    <string name="set_as_wallpaper">Définir comme fond d\'écran</string>
    <string name="animals">Animaux</string>
    <string name="arts">Arts</string>
    <string name="nature">Nature</string>
    <string name="layout_ads">Publicités de mise en page</string>
    <string name="onboard_1">Intégration 1</string>
    <string name="onboard_2">Intégration 2</string>
    <string name="onboard_4">Intégration 4</string>
    <string name="english">Anglais</string>
</resources>
```
